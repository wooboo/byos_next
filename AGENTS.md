## Agent skills

### Issue tracker

Issues and PRDs live in GitHub Issues for `wooboo/byos_next`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-label triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain documentation layout. See `docs/agents/domain.md`.

### Pull requests

Before creating a pull request, run `pnpm fallow` and review the fallow report for new dead code, duplication, or health issues.
